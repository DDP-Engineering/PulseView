## Log

- 2026-08-31 frame: Scope: the first emulated aarch64 AppImage build (log .work/logs/arm64-appimage-build.log line 315) died at "linuxdeployqt: cannot execute binary file: Exec format error" - the type-2 AppImage magic AI\x02 at ELF offset 8 defeats qemu's binfmt_misc magic match, so an emulated arm64 container cannot exec any AppImage-format tool; fix is to zero those three padding bytes in Dockerfile.appimage after checksum verification, for both appimagetool and linuxdeployqt.
- 2026-08-31 frame: Quick path: no new externally observable behavior or dependency - the same pinned tools install, they just become executable under emulation; existing REQ-PLAT-0e73bea7 (builder provisioning) and REQ-PLAT-aa8d5d46 (aarch64 AppImage from an emulated container) already cover the behavior; same branch as TASK-efc19bd8, whose validated candidate this extends before anything is committed.
- 2026-08-31 frame: Environment finding recorded alongside: the Git Bash -> wsl.exe bridge reports exit 0 even for `docker run --rm ubuntu:22.04 false` and for a bare `false`, so build success on this path is judged by an explicit success sentinel in the log plus artifact presence, never by the bridge's exit code.
- 2026-08-31 build red: command=`bash 02_Tools/test/arm64_tools_lock_test.sh`; exit=1; expected missing behavior=Dockerfile.appimage neutralizes the AppImage magic on 0 tools, expected both; the live red is the failed emulated build itself (Exec format error at line 191, log line 315).
- 2026-08-31 build green: test exit=0 after adding `printf '\0\0\0' | dd ... seek=8 count=3 conv=notrunc` after each tool's sha256 verification in Dockerfile.appimage.
- 2026-08-31 build: second environment finding - the qemu binfmt registration does NOT survive a WSL VM restart: the first rebuild attempt failed with "exec /usr/bin/bash: exec format error" because /proc/sys/fs/binfmt_misc/qemu-aarch64 had vanished between builds; re-registered with the tonistiigi/binfmt one-liner (this is exactly the gap check_host.sh's arm64 probe reports).
- 2026-08-31 build manual observation: image rebuilt (IMAGE-REBUILD-OK, record 20260831T092716Z-appimage-arm64); live probe inside the emulated arm64 container: `linuxdeployqt --version` and `appimagetool --version` both execute and print (TOOLS-EXEC-OK) - the exact operation that failed before the fix.
- 2026-08-31 validate: the emulated aarch64 AppImage build then completed end to end (84 libraries bundled, closure complete, APPIMAGE-BUILD-OK) and the artifact passed identity, CLI, driver and decoder verification on bare arm64 containers; check errors=0, remaining warnings pre-existing or explained in TASK-7c6c47dc.
- 2026-08-31 deliver: outcome is the user's commit on feature/arm64-linux-build; closed out so that commit carries the journal.
